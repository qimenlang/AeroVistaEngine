# 多通道同步模块设计

面向本项目 **1 Host + 多 IG（IP 可不同，目标约 10 通道）**。  
TCP/UDP、端口与连通性见 [socket总结.md](./socket总结.md)。  
验收规格：`engine/Tests/HostIGTests.cpp`（Catch2 BDD）。

---

## 0. 初步同步：范围与目标

**初步同步**要先跑通「多通道跟同一 Host 节拍 + 共用眼点 + 通道视锥相邻」，不追求显示卡 Genlock / 亚毫秒校时。

| 纳入初步 | 暂不纳入 |
|----------|----------|
| 连接：TCP 命令面 + UDP 同步面握手 | RTT / NTP 式时钟 offset |
| FreeRun：Host 按帧自动发 IGCtrl（不等 SOF） | Barrier 等齐再发下一帧（可后加 `frameGate`） |
| IG 用 IGCtrl.`TimeStamp` 作模拟时间（矫正 + 可选外推） | 独立 Host 进程（先挂 Engine） |
| 每收到 IGCtrl 回一条 SOF（健康 / 掉帧观察） | 可靠 UDP、丢包重传 |
| 每帧状态含共用眼点；各 IG 本地标定算 frustum | 实体级全量状态同步细则 |
| 1 主窗（Host+IG）+ N 从窗（仅 IG）Engine 集成 | 边缘融合 / 几何精标定工具链 |

## 1. 职责划分

| 类型 | 职责 |
|------|------|
| **IgSync** | UDP bind、`Connect(Host)`、收 `IGCtrl`/状态、回 `SOF`；TCP 收命令并 ACK/NACK |
| **HostSync** | UDP bind + TCP `listen`、收各 IG 的 `SOF`、按帧扇出 `IGCtrl`/状态；TCP 下发命令；维护 IG 表 |
| **SynchronSystem** | Engine 门面：挂 loop；持有 **IgSync**；可选持有 **HostSync**；把同步状态应用到相机/场景 |
| **Engine** | 帧循环 `preFrame / update / render / postFrame`；坐标系与「无新包」策略可配 |

```text
Engine::tickOnFrame
  preFrame  → SynchronSystem 收包（入队，不写相机）
  update    → handleEvents → SynchronSystem::update（全体 IG 写 Host 眼点）→ viewer update
  render
  postFrame → 输入 IG 上报 intent；Host 扇出 IGCtrl + 眼点给全体 ready IG（含 A）
```

### 1.1 HostSync 进程边界

- **最终**：HostSync 独立进程；ABC 均为纯 IG，行为一致。  
- **当前**：HostSync 可暂挂主窗 Engine，但眼点路径仍走「IG 上报 → Host 扇出 → IG 回灌」，不为 A 开本地直写旁路。  
- 拆进程后：Engine 侧仅留 IgSync。
### 1.2 多窗口用法

典型：3 Engine——A 主窗（Host+IG），B/C 从窗（仅 IG）；桌面相邻、frustum 相邻。

#### 坐标系与位姿表示

- **默认：世界坐标系**（与当前 Engine / LookAt / Trackball 一致：Y-forward、Z-up）。
- **暂不使用椭球坐标系**。
- Engine：`setCoordinateFrame(World | …)`；现阶段实现以 World 为准。
- **`setCameraPose` / 眼点报文：仅 `position` + 欧拉角（euler）**，不用四元数作为对外接口。

#### 通道标定配置

- 路径约定：`engine/resources/config/`（启动时传入配置文件路径）。
- 文件：**`left.xml`**、**`right.xml`**——只存相对主视向的 **偏移角度**（如 yaw；可扩展 pitch/roll）。
- **中通道（A）偏移为 0**，可不配 xml；左右通道读对应文件。
- Engine 启动读取本通道 xml（若有）→ 偏移角；收 Host 眼点后：  
  `最终位姿 = Host(pos+euler) ⊕ 本地偏移角` → `setCameraPose`。

#### Host 权威眼点（ABC 作为 IG 行为一致）

目标：A/B/C 均为 IG，**最终渲染位姿一律来自 Host 回灌**；便于 Host 拆成独立进程后无需改 IG 侧逻辑。

```text
A Trackball → intent（世界系 pos+euler，非渲染权威）
  └─ 上报 Host（当前同进程也走该路径；拆进程后为 UDP/TCP）
Host 缓存权威眼点
  └─ 扇出 EntityPositionCtrl → 全体 ready IG（含 A、B、C）
各 IG：preFrame 入队 → update：Host 眼点 ⊕ 本地偏移 → setCameraPose(pos, euler)
```

约定：

- **拆分 intent 与渲染位姿**：Trackball 只产生 intent 上报 Host；**禁止**用「本帧已 `setCameraPose` 的 mainCamera」作为下一帧 Host 发送源（避免回声环）。
- Host 只发 **同一主 view 眼点（pos+euler）**；左右偏航来自各 IG 本地 xml，中通道偏移 0。
- **眼点扇出目标 = 全体 ready IG（含 A）**；不为 `enableHost` 本机开例外旁路。
- 频率 = Engine fps；典型延迟 ≥1 帧（拆进程后另加 RTT）；ABC 同延迟模型，尽量同步。
- 同进程阶段也须走「上报 → Host 扇出 → IgSync 收 → update 应用」，保证拆 Host 后行为不变。

#### IG：连接 / 无新包 / 断线（ABC 相同）

| 状态 | 相机驱动 |
|------|----------|
| 从未连接 / 独立预览 | 本地 Trackball / 键盘（可直接写相机） |
| 已连接且本帧收到新 Host 眼点 | 更新缓存，**Host 位姿为准**（+ 本地标定） |
| 已连接但本帧无新包 | 由 **无新包策略** 决定（见下） |
| 断开连接 | **保留最后一帧 Host 位姿**（+ 标定；不自动跳回断线前的 Trackball 状态） |

**无新包策略**（已连接时，Engine 可配，二选一）：

| 策略 | 行为 |
|------|------|
| **ReuseLast（沿用）** | `SynchronSystem::update` 仍用上一帧缓存的 Host 眼点写相机 |
| **Freeze（冻结）** | 本帧不再改写相机 LookAt（停在上一帧已写入结果；Trackball 仍被「已连接」逻辑抑制） |

```text
Engine::setHostEyeStalePolicy(ReuseLast | Freeze)   // 默认建议 ReuseLast
```

#### IG：单帧写入时机（覆盖 Trackball）

```text
preFrame:  IgSync 收包入队（不写相机）
update:
  handleEvents()                 ← Trackball 更新 intent（已连接时勿当作最终渲染）
  SynchronSystem::update()       ← 已连接则按缓存/新包 setCameraPose（覆盖本地）
  viewer->update()
render / postFrame               ← 输入 IG 上报 intent；Host 扇出
```

勿在 `handleEvents` **之前**写 Host 眼点。主窗 A 与从窗 B/C：**同样**在 `SynchronSystem::update` 应用 Host 回灌。

相机访问：`Engine::mainCamera()`；HUD 相机不同步。
#### 通道 frustum 拼接（标定）

眼点相同（世界系）；投影参数一致时，水平相邻靠偏航：

- `aspect = 宽/高`；`hFOV = 2·atan(aspect·tan(vFOV/2))`
- 三通道硬拼：中 `yaw=0`，左/右 `yaw=±hFOV`；融合则 `±(hFOV−overlap)`
- 标定存各 IG 本地；同步包只更新共用眼点

### 1.3 Loop 相位（`preFrame / update / render / postFrame`）

```text
preFrame:   SynchronSystem 收 UDP（IGCtrl、EntityPositionCtrl…）→ 入队
update:     handleEvents → SynchronSystem::update（全体 IG 应用 Host 眼点）→ viewer update
render:     record / present
postFrame:  输入 IG 上报 intent → Host 更新权威眼点
            HostSync 扇出 IGCtrl + EntityPositionCtrl → 全体 ready IG（含 A）
            IG 回 SOF（若本帧处理了 IGCtrl）
```

## 2. 时钟、节拍与报文

### 2.1 模拟时间（现阶段）

- IG 模拟时间 = IGCtrl.`TimeStamp`（`TimeStampValid=true`）。
- **单位：微秒（µs / us）**；**来源：Host**（Host 在 `postFrame` / `HostSync::Update(simTimeUs)` 填入并下发）。
- 不做 RTT offset；单向时延吃进误差。

```text
收 IGCtrl(H_us)：sim = H_us，锚点 (H_us, L_recv)     ← 矫正
之后：sim(L) = H_us + (L - L_recv)（换算到同一单位） ← 外推
```

乱序/迟到：只接受 `FrameCntr` **不小于** 当前已处理帧的包（旧包丢弃）。

### 2.2 节拍策略

| 配置项 | 含义 | 初步默认 |
|--------|------|----------|
| `igCtrlSendPace` | 何时发下一帧 IGCtrl | **FreeRun**（按调用方 fps，不等 SOF） |
| `frameGate` | 是否等齐 SOF 再允许下一显示帧 | **FreeRun**（Barrier 后期） |

```text
SetPaceConfig(SyncPaceConfig{ igCtrlSendPace, frameGate, targetFps, barrierTimeoutMs })
HostSync::Run() → RUNNING
HostSync::Update(simTime) → 本帧扇出 IGCtrl（FreeRun 不得阻塞等 SOF）
```

- **一次 `Update` = 一轮扇出**（对每个 ready IG 各发一份相同逻辑帧；`igCtrlSentCount` 计轮次，不是 UDP 包总数）。  
- 50ms beacon 仅握手/保活，不当主钟。

### 2.3 报文字段

| 报文 | 方向 | 字段 | 用途 |
|------|------|------|------|
| IGCtrl | Host→IG | `TimeStamp`/`Valid` | 模拟时间主钟 |
| IGCtrl | Host→IG | `FrameCntr` | 帧身份、落后检测 |
| EntityPositionCtrl | Host→**全体 ready IG（含 A）** | 共用眼点：世界系 **pos + euler** | 每帧随 fps；权威源为输入 IG 上报的 intent |
| （intent 上报） | 输入 IG→Host | Trackball 产生的 pos+euler | 每帧；与渲染用 mainCamera 分离 |
| SOF | IG→Host | `FrameCntr` 回显 | 健康、掉帧；**不门控** FreeRun 发帧 |

SOF：每成功处理一条 IGCtrl 回一条；丢 SOF 不阻塞下一 IGCtrl。

## 3. 双平面与拓扑

| 平面 | 通道 | 流量 | 必达 |
|------|------|------|------|
| sync | UDP | IGCtrl、SOF、心跳、每帧状态 | 否；丢了用下一帧 |
| command | TCP | 加载/切库/复位等 + ACK | 是 |

```text
HostSync UDP :8000  ← SOF / 握手
         sendto → 各 IG:udpRecv（IGCtrl）
HostSync TCP :8100  ← 各 IgSync connect
```

默认端口：Host 收 **8000**、发 **8001**；TCP **8100**。同机多 IG：`udpRecv` 必须不同（8001/8003/8005…）；多机可同用 8001。

Peer 表：`{id, ip, udpRecvPort, tcp, ready}`。接入时学习 udpRecv。

## 4. 配置与 API（与 BDD 对齐）

```text
AddressConfig     { addr, udpPortSend, udpPortRecv, tcpPort }
SyncPaceConfig    { igCtrlSendPace, frameGate, targetFps, barrierTimeoutMs }
SyncRoleConfig    { enableHost, enableIg, hostLocal, igLocal, hostEndpoint }
HostEyeStalePolicy { ReuseLast, Freeze }   // 已连接且本帧无新眼点包
CoordinateFrame    { World, … }            // 默认 World；暂不用 Ellipsoid
```

| API | 说明 |
|-----|------|
| `HostSync`/`IgSync::Initialize` | 本地传输；未连接 |
| `IgSync::Connect(host)` | TCP + UDP 握手 |
| `HostSync::Run` / `Update(simTimeUs)` | `simTime` 单位 **us**，Host 提供；每轮扇出 |
| 眼点 intent 上报 | 输入 IG（现阶段 A）→ Host；与渲染位姿分离 |
| 眼点扇出目标 | **全体 ready IG（含 A）** |
| `IgSync::Update` / 收包 | preFrame 侧入队；SOF 按需回 |
| `SetPaceConfig` | 发送节拍 / 进帧门控 |
| `Engine::setCoordinateFrame` | 默认 World |
| `Engine::setHostEyeStalePolicy` | 无新包：ReuseLast / Freeze |
| `Engine` 启动参数 | 通道标定路径（`left.xml` / `right.xml`；中通道可无） |
| `Engine::mainCamera` / `setCameraPose(pos, euler)` | 世界系；欧拉角；已连接时由 Host 回灌写入 |
| `SynchronSystem::update` | 全体 IG：Host 眼点 ⊕ 本地偏移 → `setCameraPose` |
| `SynchronSystem::queueHostEyePose` 等 | 测试/入队 |
| 计数器 | `igCtrlSentCount`、`igCtrlReceivedCount`、`sofSent*` |

连接状态：`tcpConnected` / `udpSynced`；Host `readyIgCount`。

## 5. BDD 验收要点

| 场景 | 断言要点 |
|------|----------|
| 连接 | 单/多 IG Connect；错 UDP 端口失败 |
| 帧契约 | `Update`×N → `igCtrlSentCount==N`；收包 ≤N |
| SOF | `sofSent == igCtrlReceived`；`sofReceived ≤ sofSent` |
| FreeRun | `sendSof=false` 时仍发齐，`sofReceived==0` |
| Engine×1 / ×3 | IGCtrl/SOF；B/C 可用 `initSync`+`tickSync` |
| 相机 API | `mainCamera` + `setCameraPose` |
| 已连接覆盖 Trackball | `queueHostEyePose` → 本地位姿 → `SynchronSystem::update` → Host 位姿 |
| 未连接不覆盖 | `update` 后仍为本地位姿 |
| （待补）A intent→Host→ABC 回灌、EntityPositionCtrl pos+euler、left/right.xml、无新包/断线 | 见 §6 |

## 7. 角色流程（摘要）

```text
A: HostSync.Initialize + IgSync.Initialize/Connect（主窗）
B/C: IgSync.Initialize/Connect → Host readyIgCount 增加
Host.Run + 每帧 Update(simTime) 扇出 → 各 IG Update 收包/应用/回 SOF
```

命令面：带 `seq` 的 TCP 命令 → ACK/NACK → 超时重试、幂等。
