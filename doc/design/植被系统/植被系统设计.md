# 植被系统设计

实例组从哪来。一块地形格、一个物种，得到模型路径和三块数组。所有实例组共用一个锚点：有椭球时本文给出唯一 LLA，没有椭球时不给 LLA。挂接见 [实例渲染设计.md](../引擎基础功能/实例渲染设计.md)。普通 CIGI 实体仍走 [实体管理设计.md](../引擎基础功能/实体管理设计.md)。摆放、近远、风的目标见 [功能目标梳理.md](./功能目标梳理.md)。

**一句话**：实例位姿不进 JSON。以后的输入是 Cesium quantized-mesh 地形格 `(level, x, y)`。读到地形格之前，用 §4 的切平面网格产出这一个实例组。多块地形格共用哪一个 LLA、挂上之后要不要挪锚点，这一版不写。Cesium、植被掩码和撒点规则这一版仍不做。

## 1. 目标与范围

**做**（替身已挂上，见 §6）：

| 项 | 说明 |
| --- | --- |
| 实例组 | 一块地形格 × 一个物种 = 模型路径 + 三块等长数组。数组相对唯一锚点（§2） |
| 锚点 | 所有实例组共用一个。有椭球时本文给出唯一 LLA；没有椭球时不给 LLA。父矩阵由实例渲染设计写成 `computeLocalToWorldTransform` 或单位矩阵。这一版的 LLA 见 §4 |
| 替身 | 还没有地形格时，用 §4 的数组；有椭球时再用 §4 的 LLA |

**这一版不写**：把 Cesium 引进仓库；植被掩码或树木掩码；按土地覆盖决定种在哪、哪个物种、多密、用哪一层、要不要躲开水面；航向怎样变成四元数。替身的模型和网格见 §4，不代替这些规则。数组怎样挂上场景见 [实例渲染设计.md](../引擎基础功能/实例渲染设计.md)。

## 2. 实例组

实例组不是 CIGI 实体：无 `id`，不进 Host 权威表，也不进 `_entityMap`。

`entities.json` 顶层只有 `entities`。`instancingEntities` 是未知键，`loadEntitiesFile` 与 `loadHostEntityCatalog` 都拒绝。位姿不写在这份文件里，也不另存一份位姿文件。替身的数字是代码常量。

交给实例渲染设计的是各组的模型路径和三块数组。有 `EllipsoidModel` 时另给唯一的一个 LLA，没有时不给。

| 字段 | 内容 |
| --- | --- |
| 模型 | 该物种的 glTF。物种怎样对应到文件，见 §5 |
| `translations` | 相对唯一锚点的米。有椭球时是该 LLA 的东、北、天；没有椭球时是世界米 |
| `rotations` | 相对同一个锚点的四元数。航向怎样换成四元数，见 §5 |
| `scales` | 每棵的缩放 |

三块数组等长，且都在。锚点矩阵不在本文计算。有椭球时，实例渲染设计用 `computeLocalToWorldTransform(本文的唯一 LLA)`；没有椭球时用单位矩阵。多块地形格选哪一个 LLA，这一版不写，见 §5。

## 3. 地形格

**写死：一块地形等于 Cesium quantized-mesh 在某一层上的一格。** 默认投影 EPSG:4326，编号 TMS，Y 从南极起。第 `L` 层经度方向 `2^(L+1)` 格，纬度方向 `2^L` 格。边界由编号直接算出：

```text
west  =  x      / 2^(L+1) * 360 - 180
east  = (x + 1) / 2^(L+1) * 360 - 180
south =  y      / 2^L     * 180 - 90
north = (y + 1) / 2^L     * 180 - 90
```

格心经纬度是这四条边的中点。这一版不用格心当锚点。文件按这个格子切好，常见路径 `{level}/{x}/{y}.terrain`。网格顶点的经纬高是格内 16 位整数。随瓦片可选的扩展是逐顶点法线和水面掩码。没有植被掩码，也没有树木掩码。

用哪一层、何时取哪一格、多块格子共用哪一个 LLA 当锚点，这一版不写。本仓库还不读这种瓦片。3D Tiles 的内容包围体不是这里的格子。读到格子之前，用 §4。

## 4. 无地形挂接替身

**写死：还没有地形格时，不论有没有 `EllipsoidModel`，都产出一个实例组并交给实例渲染设计。** 不另加开关。查看场景是 `scene_local.json` 和 `scene_seam_grid.json`。`scene_local.json` 没有椭球，锚点矩阵是单位矩阵，同一套数组挂在世界原点附近。`scene_seam_grid.json` 会注入椭球，锚点矩阵是 `computeLocalToWorldTransform(下面这个 LLA)`。`scene_ecef.json` 和 `default.json` 也会挂，不再当作例子。

锚点 LLA 只在有椭球时使用，写死为北纬 39.9087°、东经 116.3975°、高度 0。高度不采样地形。挂上之后不改。

100 棵，10×10，间距 10 米，网格中心在锚点，天向为 0。第 `k` 棵是

```text
e = (k % 10) - 4.5
n = (k / 10) - 4.5
translations[k] = (e * 10, n * 10, 0)    // 米。有椭球：该 LLA 的东、北、天；无椭球：世界米
```

`k` 从 0 到 99。同一行从西到东，再往北换一行。`rotations[k]` 是单位四元数 `(x, y, z, w) = (0, 0, 0, 1)`。`scales[k]` 是 `[1, 1, 1]`。

模型路径写死为 `models/trees/SM_BlackAlder_Field_01/SM_BlackAlder_Field_01.gltf`。锚点、棵数、间距和路径都是代码常量，不进 `entities.json`。

这个实例组按 [实例渲染设计.md](../引擎基础功能/实例渲染设计.md) 挂上。以后有地形格，换掉三块数组的来源。共用锚点选哪个 LLA，这一版不写。挂接方式不变。这片网格不是土地覆盖撒点。

## 5. 暂时不做

| 项 | 原因 |
| --- | --- |
| 引进 Cesium、按格子生成数组 | 格子定义见 §3。读瓦片、采样格心高程还没做。无地形时用 §4 填数组 |
| 多块地形格的共用锚点、挂上后挪锚点 | 这一版锚点固定，有椭球时 LLA 只用 §4。选哪个点、要不要改矩阵，以后再写 |
| 植被掩码、树木掩码、撒点 | Cesium 地形不提供植被掩码。种在哪、哪个物种、多密、用哪一层、水面是否排除，见 [功能目标梳理.md](./功能目标梳理.md) §1。§4 的网格不代替这些规则 |
| 航向到四元数的轴序 | 替身写单位四元数。具体轴序等撒点时再定 |
| 物种对应哪份模型 | 替身的路径见 §4。以后的对应随撒点一起定 |
| 风、近远切换、阴影 | 见 [功能目标梳理.md](./功能目标梳理.md)。这版不覆盖 |

`engine/resources/config/instancingConfig.json` 不是本契约。
