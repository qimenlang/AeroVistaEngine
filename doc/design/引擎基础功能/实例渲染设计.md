# 实例渲染设计

把所有实例组挂进同一个锚点。一行 `translation`、`rotation`、`scale` 是一个实例。同一模型、一个 `InstanceNode` 和三块等长数组是一个实例组。全部实例组共用一个双精度 `MatrixTransform`，它就是锚点。普通 CIGI 实体仍走 [实体管理设计.md](./实体管理设计.md)。

**一句话**：有 `EllipsoidModel` 时，锚点矩阵是 `computeLocalToWorldTransform(调用方给出的唯一 LLA)`。没有椭球时，锚点矩阵是单位矩阵，平移是 `(0,0,0)`。每个实例组是这个锚点下面自己的 `InstanceNode`。同一模型路径只读一次。挂上之后不改这一个矩阵。

## 1. 实例组的输入

实例组不是实体：无 `id`，无 `Switch`，挂上即可见，不进 Host 权威表，也不进 `_entityMap`。

三块数组都在，长度相同。`translations` 是 `vec3`（float），`rotations` 是 `quat`，`scales` 是 `vec3`。赋给该实例组自己的 `InstanceNode`：`setTranslations` / `setRotations` / `setScales`。`firstInstance` 为 0，`instanceCount` 等于数组长度。`setRotations` 只接受 `quatArray`，节点上没有欧拉角槽。

调用方给出相对这一个锚点的三块数组。有 `EllipsoidModel` 时再给出唯一的 LLA：锚点矩阵等于 `computeLocalToWorldTransform(这个 LLA)`，平移和旋转是该点的东、北、天。没有椭球时不给 LLA：锚点矩阵是单位矩阵，平移和旋转就是世界米。本文不采样地形，也不算格心。不从第一条实例反推锚点。没有任何实例组挂上时，不留下空的锚点。

## 2. 运行时场景图

模型文件是普通刚体 glTF，文件里没有实例位姿。读之前打开 `instanceNodeHint` 的 `INSTANCE_TRANSLATIONS`、`INSTANCE_ROTATIONS`、`INSTANCE_SCALES`，叶子建成 `InstanceDraw` 或 `InstanceDrawIndexed`。三块数组在读完之后写入 `InstanceNode`。不改 glTF 加载器。

```text
Group                         // 与普通实体的 MatrixTransform 同一个父节点（_mainScene）
  MatrixTransform             // 唯一锚点。双精度。有椭球：computeLocalToWorldTransform(唯一 LLA)；无椭球：单位矩阵
    InstanceNode              // 一个实例组自己的三块数组，firstInstance = 0
      child = 已读入的子图       // 叶子是 InstanceDraw 或 InstanceDrawIndexed
    InstanceNode              // 另一个实例组。数组不合并
```

锚点是实体 `MatrixTransform` 的兄弟，不挂进模型文件自己的根。装配发生在对这个 Group 做 `ComputeBounds` 之前。`ComputeBounds` 不进入这个锚点，默认相机的包围盒不含这些实例组。没有 `camera.pose` 时，默认相机仍按 [位姿配置设计.md](../多通道同步/位姿配置设计.md) §4 对这个 Group 里其余节点取景。

同一模型路径的各实例组共用同一份已读入的子图。每一个实例组仍有自己的 `InstanceNode` 和三块数组。实体缓存里的同路径节点是普通几何，和这份实例子图不是同一个节点。替身只有一个实例组，共用要等多个实例组一起出现才看得到。读入的子图直接作为 `InstanceNode` 的 `child`。子图里还有什么节点，不在这里判断。

## 3. 加载与失败

装配发生在 `initSceneFromConfig` 返回之后、`attachConfiguredGroundGrid` 之前。此时场景有没有 `EllipsoidModel` 已经确定，用来选择锚点矩阵。普通实体已经挂在同一个父 Group 上。这一步在 `finishGraphicsAfterScene` 的 `ComputeBounds` 和 `compile` 之前。不进 `_entityMap`，也不进 `initSync`。全序见 [实体管理设计.md](./实体管理设计.md) §8。

**模型文件读不到则跳过该实例组并记日志**，其它实例组继续，`init` 不因此失败。一个都没挂上时，不留下空的锚点。

## 4. 暂时不做

| 项 | 原因 |
| --- | --- |
| 实例颜色 | 官方 VSG 的矛盾：打开 `INSTANCE_COLORS` 时，glTF 加载器把 `vsg_Color` 定成步长 16 的 `VK_FORMAT_R32G32B32A32_SFLOAT`，`InstanceNode::setColors` 却只接受步长 12 的 `vec3Array`。本版不改 VSG，也不做实例颜色 |
| `BLEND` 的深度排序 | `instanceNodeHint` 不是 `INSTANCE_NONE` 时，加载器对 `alphaMode: BLEND` 打开混合，但不建 `DepthSorted`。半透明面按场景图里的固定顺序画。`MASK` 不受影响。这版照常挂上，不因此跳过，也不补排序 |
| glTF 骨骼蒙皮 | 不改加载器，也不因关节跳过。关节怎么画由 VSG 决定 |
| 挂上之后更换锚点、多块地形格选哪一个 LLA | 这一版锚点矩阵固定。选点见 [植被系统设计.md](../植被系统/植被系统设计.md) §5 |

本文只接收已经写好的 `quat`。航向到四元数的轴序见 [植被系统设计.md](../植被系统/植被系统设计.md)。
