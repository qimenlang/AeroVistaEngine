# 实体与运动控制设计

面向本项目 **1 Host + 多 IG** 的实体**控制面**：**Host 是运行态权威**，用 CIGI 4.0 标准报文驱动 IG 侧实体的**显示状态**与**位姿摆放**（动画见 §12 `[扩展]`）。报文只传 `EntityID`，路径不经网络。

**IG 侧实体实例、目录、启动预建、Switch 显隐落地不属于本模块**，权威设计见 [实体管理设计.md](../引擎基础功能/实体管理设计.md)。

**一句话**：Host 下发 `CigiEntityCtrlV4`（显隐/属性）与 `CigiEntityPositionCtrlV4`（位姿）；链路按语义选择——一次性 / 配置 / 请求走 TCP，持续实时位姿走 UDP（沿用 [cigi梳理.md](../../notes/cigi梳理.md)）。IG 按 [实体管理设计.md](../引擎基础功能/实体管理设计.md) 执行。`CigiAnimationCtrlV4` 为首版之外（§12）。

## 1. 目标与范围

**做**：

| 项 | 说明 |
| --- | --- |
| Host 权威 | 运行期显隐由 Host 用 `CigiEntityCtrlV4` 驱动；IG 实例已启动预建（[实体管理设计.md](../引擎基础功能/实体管理设计.md)） |
| 位姿摆放 | `CigiEntityPositionCtrlV4`（`EntityID≠0`）控制实体位姿（恒 Detach+LLA，见 §4.2） |
| 路径映射 | 报文只传 `EntityID`；目录文件契约见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §4。Host 读同一份文件的**子集**建权威表（§3.2） |

**成功标准**：Host 能通过网络命令让各 ready IG 把指定 id **显示/隐藏**、摆放到指定位姿；后加入 IG 收到全量当前权威状态。IG 落地行为以 [实体管理设计.md](../引擎基础功能/实体管理设计.md) 验收码 `ENT-02-*` / `ENT-03-*` 为准。

## 2. 背景与现状

## 3. 权威模型

**写死：Host 是实体运行态权威，IG 是执行端。**

- **Host**：维护实体权威状态表（各 id 当前 `Active` / `Standby`、last pose、alpha），决定何时显/隐，下发位姿。表落在 sync 库 `HostDataManager`，由 viewhost `HostDriver` 编排发送（§3.2）。
- **IG**：实例与几何在启动预建（[实体管理设计.md](../引擎基础功能/实体管理设计.md) §8）；运行期收到报文只切显隐 / 写位姿。
- **方向**：首版 Host → IG（`EntityCtrl` / `EntityPositionCtrl`）。`AnimationCtrl` 见 §12。

### 3.1 实体显示状态全局一致（写死，2026-09 拍板）

**同一实体在所有 IG 上的显示状态恒相同；不存在 per-IG 独立的实体显示状态。实体「是否存在」是 IG 启动预建的既定事实（[实体管理设计.md](../引擎基础功能/实体管理设计.md) §3），不属于运行时状态。**

理由：1 Host + N IG 是同一个世界的多视口投影——各通道差异只在相机偏移（[多通道同步模块设计.md](./多通道同步模块设计.md) §3.2），不在世界内容。

推论：

| # | 推论 |
| --- | --- |
| 1 | Host 只需维护**一份**实体状态表，无 per-IG 状态列；viewhost 实体树每项显示单一状态（[viewhost设计.md](../viewhost设计.md) §4.8） |
| 2 | 向全体 IG **广播**同一 `EntityCtrl` 是正确形态；per-peer 定向发送不是前置依赖。**触发时需识别「新增 vs 重连回升」peer**（#20 B），识别只用于决定是否广播 |
| 3 | 向已就绪 IG 广播/重放「当前权威状态」都安全——IG 要么已处于该状态（no-op），要么正需补齐（**后加入**）。**不含掉线重连 IG**——重连补发未设计（决策日志：掉队保持未同步、host 不补发，待定） |

> **唯一的 per-IG 概念是「加载失败」**：某台 IG 启动预建失败则该实体缺失。首版不上报（[实体管理设计.md](../引擎基础功能/实体管理设计.md) §7.1）。

### 3.2 Host 侧落点（写死：`HostDataManager` + `HostDriver`）

分层契约主文在 [viewhost设计.md](../viewhost设计.md) §4.0 与 [sync模块化设计.md](./sync模块化设计.md) §3.4。本文只固定**实体表**语义：

- `HostDataManager`（`aerovista::sync`）持实体权威表：由 `entities.json` 子集（`id` / `name` / `model` / `initialEntityState` / **`pose.ellipsoid`**）初始化；运行期更新显隐、last pose、alpha 只改内存表、不回写文件。按当前行填 `CigiEntityCtrlV4` 与 `CigiEntityPositionCtrlV4`。
- **表内位姿（写死，2026-09）**：同步只 LLA，行内存 `lat/lon/alt` + `yawDeg/pitchDeg/rollDeg`。建表读 `pose.ellipsoid`（`lla` + `eulerYprDeg`），缺省或仅有 `pose.local` → 全 0（`local` 半轨只服务 IG 预建，[位姿配置设计.md](./位姿配置设计.md)）。提交（`setEntityPose` + `sendEntity`）覆盖 last pose 后再组包。
- `HostDriver` 持有 `HostSync` + `HostDataManager`：UI 意图与 **ready 全量广播**（§7）都走 Driver——先写表再组包再 `flushTcp`。Dlg 不组包、不直接绑表字段；属性面板初值来自 `snapshot()`，编辑框是草稿，**Apply** 才写表（[viewhost设计.md](../viewhost设计.md) §4.0 / §4.8）。
- `HostSync` 只传输，不持实体表。

ownship 眼点不进该表（[lla位姿传输设计.md](./lla位姿传输设计.md)）。其它报文族以后仍进同一 `HostDataManager`（[多通道同步模块设计.md](./多通道同步模块设计.md) §9 P2）。

目录文件位置与完整 schema 见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §4。

## 4. 报文

### 4.1 `CigiEntityCtrlV4` —— 实体显隐控制

`PacketID = 0x25`，`PacketSize = 16`。字段（`CigiEntityCtrlV4.h` / `CigiBaseEntityCtrl.h`）：

| 字段 | 类型 | 本设计用途 |
| --- | --- | --- |
| `EntityID` | uint16 | **映射主键**；`0` 保留 ownship（本报文不用于眼点） |
| `EntityState` | enum | 显隐：`Standby=0` / `Active=1` / `Destroyed=2`（IG 首版降级为 `Standby`，见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §7） |
| `EntityType` | uint16 | **不使用**，默认填 `0`（IG 忽略该字段） |
| `Alpha` | uint8 | 透明度 0–255 |
| `InheritAlpha` | enum | `NoInherit=0` / `Inherit=1` |
| `CollisionDetectEn` | enum | `Disable=0` / `Enable=1`（IG 仅存值） |
| `SmoothingEn` | bool | 运动平滑开关（IG 仅存值） |
| `ExtendedEntityType` + 七段 DIS 类型 | — | **不使用**（`ExtendedEntityType=Short`） |

IG 如何切 Switch / 套属性见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §9。

### 4.2 `CigiEntityPositionCtrlV4` —— 位姿（同步只 LLA）

沿用既有命令面摆放语义（[状态同步设计初版.md](./状态同步设计初版.md) §4.1），命令实体位姿**恒 LLA**（[lla位姿传输设计.md](./lla位姿传输设计.md) §2）：

| 字段 | 用途 |
| --- | --- |
| `EntityID` | 目标实体；`0` = ownship 眼点（[lla位姿传输设计.md](./lla位姿传输设计.md)，本文不涉及） |
| `AttachState` | 恒为 `Detach`（同步只 LLA，2026-09 收敛） |
| `ParentID` | 首版不做父子挂载（§12）：恒 `Detach` + `ParentID=0` |
| 位置字段 | 恒 `Lat/Lon/Alt` |
| `ClampState` | 钳制模式（首版行为见 §15 #7） |

> 位姿写入走 `Entity::setPoseLla`（经 `Engine::onEntityPose` 查表，[实体管理设计.md](../引擎基础功能/实体管理设计.md) §9）。
>
> 父子挂载为 §12 扩展；`AttachState` 在首版不表达挂载关系。

### 4.3 `CigiAnimationCtrlV4` —— 动画（首版不做，§12）

`CigiBaseAnimationCtrl.h` 字段：

| 字段 | 用途 |
| --- | --- |
| `EntityID` | 目标实体 |
| `AnimationID` | 动画片段 id |
| `AnimationState` | `Stop=0` / `Play=1` |
| `AnimationLoopMode` | `OneShot=0` / `Continuous=1` |
| `AnimationSpeed` | 播放速度 |

> V1/V3 曾把动画嵌在 `EntityCtrl`；**V4 已拆到 `AnimationCtrlV4`**，不要通过 `EntityCtrl` 下发动画。IG 侧 AnimationID 映射见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §14 #1。

### 4.4 链路选择（写死）

沿用 [cigi梳理.md](../../notes/cigi梳理.md)：

| 报文 | 链路 | 频率 |
| --- | --- | --- |
| `CigiEntityCtrlV4` | **TCP**（一次性） | 事件性（显隐切换） |
| `CigiEntityPositionCtrlV4` | UDP（持续实时）/ **TCP**（一次性摆放） | 每帧 / 一次性 |
| `CigiAnimationCtrlV4` | **TCP**（一次性） | 事件性（**首版不做**） |

> 命令实体（`EntityID≠0`）位姿首版为 **TCP 一次性摆放**。「UDP 持续」用于 `EntityID==0` 眼点（[lla位姿传输设计.md](./lla位姿传输设计.md)）。勿把命令实体位姿走 UDP 帧流（§15 #9）。

Host 经 `outMsgWithIgCtrlTcp() << 报文 → flushTcp()` / `outMsgWithIgCtrlUdp() << 报文 → flushUdp()` 发送（IGCtrl 帧头自动前置，[状态同步设计初版.md](./状态同步设计初版.md) §7.1）。**无业务回执（fire-and-forget）**。

## 6. 配置与报文职责划分

**配置只放集成期静态确定的东西，运行时要变的走报文。** 引擎消费规则（启动 mask、pose 套一次等）见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §6。本文只固定 Host 侧：

| 信息 | Host 侧 |
| --- | --- |
| `initialEntityState` / `pose.ellipsoid` | 仅**首次建表**初始化权威表；此后下发一律表当前值，不回读配置 |
| 运行时显隐 / last pose / alpha | 内存表 + `EntityCtrl` / `EntityPositionCtrl`，不回写文件 |

> **后加入 IG**（集合内 ready 晚）收到广播即收敛到权威态；其按配置显示只是瞬态。**掉线重连 IG 不在此列**（§7）。

## 7. 下发时机与就绪

**写死：每个 IG 的 ready 跃变各自触发全量广播。** 不是全局只触发一次。标准时序：Host 等 IG 报 `IG Mode = Operate` 后才发实体数据，对应本项目连接层 ready。

**下发内容 = 当前权威状态（写死）**：

| 时机 | 下发内容 |
| --- | --- |
| Host 首次建表 | 由 `initialEntityState` + `pose.ellipsoid`（缺省 0）初始化 → 广播该初始显隐与位姿 |
| 后续任何一次下发（后加入 IG ready / 用户操作） | 权威表**当前值** |

> **广播重放无害（写死，依据 §3.1）**：`HostSync::flushTcp()` 当前只能向全部 `tcpReady && udpReady` 的 peer 广播。IG#2 加入触发的重放对 IG#1 无害——IG#1 收到的正是自己已处于的状态，按 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §9 幂等 no-op。
>
> per-peer 定向发送不是前置依赖。掉线重连的定向补发后续按需再议（§12 #20）。
>
> **触发实现（#20 B：需 peer 去重，写死）**：`HostSync` 现无 ready 跃变回调，仅有 `hasReadyIg()` / `readyIgCount()`。仅靠「计数上升即广播」会把**掉线重连回升**误当后加入。故 **`HostDriver`** 需记录已广播过的 IG 连接，仅在**新增** IG ready 时调 `broadcastEntityAuthority()`；**重连回升不广播**。计数下降不触发。去重键缺口见 §15 #3。
>
> **启动期重复全量——接受（写死）**：N 台 IG 依次接入时每台会收到 N 次全量（其余为 no-op）。保持现状；已否决「等齐 N 台后统一下发」。消除重复列为 §12 `[todo]` #25。

### 7.1 就绪语义

**写死：只有连接层 ready，无业务层 ready。** `HostSync::readyIgCount()`（`tcpReady && udpReady`）。就绪**不含**「模型加载完成」——几何加载是 IG 启动本地行为（[实体管理设计.md](../引擎基础功能/实体管理设计.md) §8）。场景图必须先于 `initSync`，保证 Host 在 IG ready 跃变广播时 `_entityMap` 已建全。

加载失败不上报：Host 不感知某 IG 缺某实体；viewhost 树不显示加载中/成功/失败（[viewhost设计.md](../viewhost设计.md) §4.8）。

## 8. 时序

**多 IG ready 跃变触发全量广播**：

```text
Host                                                        IG#1        IG#2
  │ readyIgCount(): 0→1（IG#1 连接层 ready）                    │            │
  │ 广播全量当前权威状态（EntityCtrl + EntityPositionCtrl 逐实体） │            │
  │ ───── TCP [EntityCtrl…][EntityPositionCtrl…] ──────────────▶ 切 Switch / 套 last pose │
  │                                                          │（no-op 幂等）│
  │ readyIgCount(): 1→2（IG#2 后加入 ready）                   │            │
  │ 再次广播全量当前权威状态                                    │            │
  │ ───── TCP ───────────────────────────────────────────────▶  no-op     │ 切 Switch / 套 last pose
```

**单实体显隐 / 位姿 / 降级**（IG 落地见 [实体管理设计.md](../引擎基础功能/实体管理设计.md) §9）：

```text
Host                                                        IG
  │ outMsgWithIgCtrlTcp() << CigiEntityCtrlV4(EntityID=1, Active)
  │ flushTcp()
  │ ───── TCP [IGCtrl][EntityCtrl(1, Active)] ────▶  onEntityCtrl → Switch ON
  │
  │ outMsgWithIgCtrlTcp() << CigiEntityPositionCtrlV4(EntityID=1, Detach, LLA)
  │ flushTcp()
  │ ───── TCP [IGCtrl][EntityPositionCtrl(1)] ────▶  onEntityPose → setPoseLla
  │
  │ EntityCtrl(Standby) / EntityCtrl(Destroyed)
  │ ───── TCP ──────────────────────────────────▶  Switch OFF（Destroyed 首版等同 Standby）
```
