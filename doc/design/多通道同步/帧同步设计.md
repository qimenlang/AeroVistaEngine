# 帧同步设计

面向本项目 **1 Host + 多 IG（约 10 通道）** 的 Present 对齐初步方案。知识见 [帧同步总结.md](../../notes/帧同步总结.md)；报文节拍见 [多通道同步模块设计.md](./多通道同步模块设计.md) §0 / §6.2；仿真时间消费见 [时钟同步方案.md](./时钟同步方案.md)；状态内容见 [状态同步设计初版.md](./状态同步设计初版.md)。

**初步方案一句话**：软件 Present Barrier（逻辑帧 = Host Frame Number → 渲完 → 等齐 → Present）；**不把 SOF 当 Barrier**。CIGI §4.2.1 / §4.2.2 **两种 Message Sync 都做**，由 **Host 配置在初始化时选定**，会话中途不切换；与 Barrier 开/关正交，便于对比节拍差和「节拍 × Barrier」差。硬件 Swap/Framelock 后期。

**与 CIGI ICD（SISO-STD-013-2014）§4.2 的关系**：§4.2 是 Host↔IG **报文节拍**，不是 Present 帧同步。SOF 在帧**开头**；Barrier 在渲**完**。统一 Host 帧号扇出两种模式都有。

## 1. 范围、实现状态与目标

### 1.1 Message Sync 实现状态（写死）

| 方式 | ICD | 本项目 | 证据 |
| --- | --- | --- | --- |
| **Asynchronous / FreeRun** | §4.2.1 | **已实现**（默认） | Host 按调用方节奏 `outMsgWithIgCtrlUdp()` 扇出，**不等 SOF**；CCL `SetSynchronous(false)`。验收 `CIGI-freerun`。SOF 每条 IGCtrl 回一条（`CIGI-sof-echo`），FreeRun 下**不门控**发帧。 |
| **Synchronous / SofGated** | §4.2.2 | **待实现** | 配置为 `sofGated` 时，Host **只认一台 master 的 SOF** 再扇出同一 IGCtrl。缺省配置仍走 FreeRun。 |

模块设计 §9 P1「Host 等齐再开帧」指等齐**所有** IG 再发下一包（全通道 lockstep），**不是** §4.2.2（认一台 master），也**不是** Present Barrier。三套集合点不要混名。

### 1.2 帧同步实现状态（写死）

| 项 | 状态 |
| --- | --- |
| 同一 Host Frame Number 扇出全体 ready IG | **已实现**（`outMsgWithIgCtrlUdp` 数据面计数器；`CIGI-frame-cntr` / `CIGI-multi-ig`） |
| 软件 Present Barrier（渲完 N 等齐再 Present） | **未实现** |
| 硬件 Swap Group / Swap Barrier | **未实现** |
| Framelock / Genlock（显示相位） | **未实现**（模块设计 §9 P2；属显示同步） |

### 1.3 纳入 / 暂不纳入


| 纳入初步 | 暂不纳入 |
| --- | --- |
| 软件 Present Barrier（§3）；FreeRun 与 SofGated 都能当上游 | 运行时热切 Message Sync（须重启 Host 进程） |
| 两种 Message Sync 都实现；`hostConfig` 初始化选定（§4） | 等齐**所有** IG 的 SOF 再发（§9 P1 全通道门闩） |
| 逻辑帧钥匙 = IGCtrl **Host Frame Number** | 用 SOF / IG Frame Number 当 Present 钥匙 |
| 掉帧策略：超时后的降级（规则见 §3.3，细则待标定） | 硬件 Swap Group/Barrier、Framelock、投影机 Genlock |
| 集合点由 **Host 汇总 ready 再放行** | IG 全互连 mesh Barrier |


**目标**：拼接非严格时，各通道 Present 的逻辑帧号一致；跨机 Present 时刻差可到数 ms（软件上限）。不追求同一 VSync 沿。用配置切换节拍，对比「只有节拍」与「节拍 + Barrier」。

## 2. 方案总览

```text
hostConfig.messageSync 在 Host initialize 钉死（§4）
  freeRun   → 调用方定时器驱动发 IGCtrl(N)
  sofGated  → 等到 master SOF 再发 IGCtrl(N)
Host 扇出 IGCtrl(N) + 状态                 同一 N，两种模式都如此
各 IG 按 N 更新并渲染
各 IG ready(N) → Host 汇总                 软件 Barrier（§3，未实现；与 messageSync 正交）
Host release(N) → 各 IG Present            仍跟各自 VSync
（可选，后期）Swap Group/Barrier + Framelock
```

与已有层的边界：

| 层 | 文档 | 本层要不要重做 |
| --- | --- | --- |
| 报文节拍 | 模块设计 §6.2 + 本文 §4 | Barrier **不**改节拍键；节拍由 `messageSync` 单独决定 |
| Timestamp / `simTimeUs` | 时钟同步方案 | 否；两种 Message Sync **都继续** `TimeStampValid=true` |
| 眼点 / 实体 | 状态同步设计初版 | 否 |
| 显示相位 | 模块设计 §9 P2 | 否 |

## 3. 软件 Present Barrier（初步，未实现）

### 3.1 逻辑帧

- **写死**：渲染/Present 对齐用的帧号是 Host→IG `CigiIGCtrlV4` 的 **Host Frame Number**（一次 `flushUdp` 对全体 ready IG 相同）。
- IG 自己的 SOF `IG Frame Number` 只用于回显/丢包观察，**不**作为 Present 钥匙（CIGI 3.2 起两套帧号独立）。

### 3.2 集合点

**写死**：

1. Barrier 发生在 **渲完 N 之后、Present 之前**。
2. **禁止**用 SOF 表示 ready(N) 或 release(N)。SOF 是帧起始心跳（现行：每条 IGCtrl 回一条）；SofGated 下 master SOF 只门控 **Host 发下一包**。
3. CIGI 标准包**没有** Present ready/release；初步走 **UDP 同步面**上的自建 `sync_proto` 或注册 Extension Packet（与高频 IGCtrl 同面，可丢则跟下一帧，细则实现时钉）。**不**改走 TCP（队头阻塞，见 [socket总结.md](../../notes/socket总结.md)）。

**初步（待实现）**：各 IG 渲完 N 后向 Host 发 `ready(N)`；Host 在已 ready 的 peer 集合上都收到 N（或触发 §3.3）后扇出 `release(N)`；IG 收到后再 `Present`。

未参与本帧的 peer（未连上、已摘除）不进入集合。与模块设计 §9 P0 断线摘除的衔接实现时再钉。

### 3.3 超时与掉帧（待标定，实现前写死规则）

软件 Barrier 必须有超时，否则一台卡住则全组永不 Present。候选（**尚未拍板**，实现前在本文钉一条）：

- 超时后：未 ready 的通道 **重复上一帧** 或 **跳过 N 跟 release 已就绪的最大帧**；
- 与时钟方案外推冻结独立：时间可继续走，画面帧号可以丢/重。

### 3.4 Engine 挂钩（待实现）

与现行 `Engine::tickOnFrame`（`preFrame` 收包 → `update` 写相机 → `render` → `postFrame`）对齐时：

- 收 `IGCtrl(N)` / 状态：仍在 `preFrame` / `update`（不变）。
- **render 之后**发 `ready(N)`，**阻塞或等待** `release(N)` 再 Present。
- 不得在 `preFrame` 用「本帧是否收到 SOF/IGCtrl」代替 ready。

具体是 viewer 的 Present 钩子还是 `postFrame` 前等待，实现时按 VSG 帧循环选型，不在本文预写 API 名。

## 4. Message Sync 配置与帧同步

### 4.1 写死

- 两种 Message Sync **都实现**；**都不是**帧同步本身。
- **禁止运行时热切**：模式在 `HostSync::initialize`（读完 `hostConfig`）钉死，直到进程退出。改模式 = 改配置并**重启 Host**。不做会话中途切换（半包在飞、Barrier 在等 `release(N)`、Host 循环从定时器换成等 SOF，状态机过重，对比收益不够）。
- Present Barrier 开/关（实现时）与 `messageSync` **正交**：对比时一次只改一个旋钮。
- SofGated 之后，SOF 仍不得当 Present ready。
- 两种模式都继续填 IGCtrl Timestamp（`TimeStampValid=true`），不因切到 Sync 就停填——避免对比里混进时钟行为变化。

利弊见 [帧同步总结.md](../../notes/帧同步总结.md) §6。

### 4.2 配置（`hostConfig`，初始化）

节拍由 **Host 进程**决定（谁发 IGCtrl），字段进 `hostConfig`（`loadHostConfig` / `HostConfig`）。IG 侧始终按条回 SOF，**不**为 Message Sync 另配开关。

JSON 字符串（camelCase）；C++ 枚举值 SCREAMING_SNAKE（`cpp-vsg-style`）。

| JSON 键 | C++ | 缺省 | 规则 |
| --- | --- | --- | --- |
| `messageSync` | `enum class MessageSync { FREE_RUN, SOF_GATED }` | 省略 ≡ `freeRun` | 只允许 `"freeRun"` / `"sofGated"`；未知值拒绝 |
| `masterChannelId` | `int masterChannelId` | 无（FreeRun 不写） | **仅** `sofGated` 必填，与 IG `syncSystem.channelId` 对应；FreeRun 下出现则拒绝（避免配了却不生效） |

```jsonc
// 缺省：与现状相同，可省略两键
{ "hostConfig": { "udpPortRecv": 8000, "tcpPort": 8100 } }

{ "hostConfig": {
    "udpPortRecv": 8000, "tcpPort": 8100,
    "messageSync": "freeRun"
} }

{ "hostConfig": {
    "udpPortRecv": 8000, "tcpPort": 8100,
    "messageSync": "sofGated",
    "masterChannelId": 0
} }
```

端口仍全必填（模块设计方案 A）。`messageSync` / `masterChannelId` 为**条件字段**，不要求「`hostConfig` 一出现两键都写」。

**SofGated 行为（待实现）**：

- Host 循环改为：等到 **master** 那条 SOF → `outMsgWithIgCtrlUdp()` 扇出全体 ready IG。不得再靠 viewhost `SetTimer` 无条件 `update()`。
- CCL 会话在 **initialize** 按模式设 `SetSynchronous`（FreeRun `false`，SofGated `true`），与 Host 循环一致；只拨 CCL 标志、定时器仍打，两种都不是。
- 非 master 的 SOF 仍计数/健康观察，**不**放行发帧。
- master 未接入或超时：不发下一数据面 IGCtrl（或按实现时钉的超时日志）；不得 silent 改回 FreeRun。

`masterChannelId` 与 peer 表如何对齐（HELLO 是否带 `channelId`）实现时钉，本文只要求配置值能唯一指出一台已 ready 的 IG。

### 4.3 Host 循环对照

| 模式 | 谁驱动发 IGCtrl | viewhost |
| --- | --- | --- |
| `freeRun` | 调用方帧循环 / `SetTimer`（现状） | 保持现逻辑 |
| `sofGated` | master SOF | 等 SOF 再调现有 `outMsgWithIgCtrlUdp` 扇出，**不要**与定时器双驱动 |

## 5. 落地顺序

1. **现在**：默认 FreeRun；软件 Present Barrier（§3）在两种节拍上都能接。
2. **`hostConfig.messageSync` + SofGated**（§4）：缺省不变；配 `sofGated` 才能走 §4.2.2。验收见 §6 `MSYNC-*`。
3. **后期**：硬件 Swap Group/Barrier；拼接墙再加 Framelock，投影机独立时序再加 Genlock。

Barrier 与 SofGated 可并行开发，互不阻塞；对比实验要两个旋钮都能用。

## 6. 验收要点

对照尚未落地的用例。对齐 [测试用例书写规范.md](../../测试用例书写规范.md)。Present 用 **`PRES-*`**；Message Sync 配置用 **`MSYNC-*`**（避开 TCP 分帧 `FRM-*`）。

> 一经分配不改号、不复用、不重排。未写用例的码表示尚未落地。

| 码 | 场景 | 形式 | 验收 | Catch2 | 状态 |
| --- | --- | --- | --- | --- | --- |
| `PRES-same-n` | 同逻辑帧上屏 | 注入 / e2e | 一次扇出后，参与 Barrier 的各 IG Present 的 Host Frame Number 相同 | `[acceptance][bdd][sync][present][PRES-same-n]` | 未写 |
| `PRES-wait-slow` | 慢通道拖全组 | 注入 | 一台未 ready(N) 时，其它通道不得先 Present N | `[acceptance][bdd][sync][present][PRES-wait-slow]` | 未写 |
| `PRES-no-sof` | SOF 不是 Barrier | 注入 | 仅有 SOF、无 ready/release 时，不得当作放行 Present | `[unit][sync][present][PRES-no-sof]` | 未写 |
| `PRES-on-freerun` | 不等 SOF 也能 Barrier | e2e | Host FreeRun 下 Barrier 仍能对齐 N | `[acceptance][bdd][sync][present][e2e][PRES-on-freerun]` | 未写 |
| `PRES-on-sofgated` | SofGated 下 Barrier | e2e | `messageSync=sofGated` 时 Barrier 仍按 N 等齐 Present，不用 SOF 当 ready | `[acceptance][bdd][sync][present][e2e][PRES-on-sofgated]` | 未写 |
| `PRES-timeout` | 超时降级 | 注入 | 超过阈值后按 §3.3 已钉规则降级，不得死等 | `[acceptance][bdd][sync][present][PRES-timeout]` | 未写（依赖 §3.3 拍板） |
| `MSYNC-default-freerun` | 缺省节拍 | unit | `hostConfig` 不写 `messageSync` ≡ `freeRun` | `[unit][config][sync][host][MSYNC-default-freerun]` | 未写 |
| `MSYNC-sofgated-master` | SofGated 要 master | unit | `sofGated` 无 `masterChannelId` → 解析失败 | `[unit][config][sync][host][MSYNC-sofgated-master]` | 未写 |
| `MSYNC-freerun-no-master` | FreeRun 禁带 master | unit | `freeRun`（或缺省）却写了 `masterChannelId` → 解析失败 | `[unit][config][sync][host][MSYNC-freerun-no-master]` | 未写 |
| `MSYNC-sofgated-wait` | master SOF 才发 | e2e | SofGated 下无 master SOF 则不再扇出下一数据面 IGCtrl；收到 master SOF 后全体 ready IG 同一 Host 帧号 | `[acceptance][bdd][sync][e2e][MSYNC-sofgated-wait]` | 未写 |

现有 `CIGI-freerun` / `CIGI-frame-cntr` / `CIGI-sof-echo` 验收的是 **默认 FreeRun 的 Message Sync / 帧号扇出**，**不**验收 Present 对齐，也**不**验收 SofGated。

## 7. 不做与扩展位


| 项 | 状态 | 何时再加 |
| --- | --- | --- |
| 软件 Present Barrier（§3） | **待实现** | 拼接或通道间错帧可观察时优先 |
| `messageSync` / SofGated（§4） | **待实现** | 与 Barrier 可并行；缺省保持 FreeRun |
| 运行时热切 Message Sync | **不做** | 对比需求用改配置重启即可 |
| 等齐**所有** IG SOF 再发 | **不做**（初步） | 模块设计 §9 P1；不要与 SofGated（单 master）混做 |
| 硬件 Swap Group / Swap Barrier | **不做** | 拼接墙 / 高等级视景 |
| Framelock / Genlock | **不做** | 显示同步；见模块设计 §9 P2 |
| IG mesh 互报 ready（无 Host 汇总） | **不做** | 无 Host 或 Host 不宜当集合点时 |
| PTP 作为 Present 对齐 | **不做** | 时钟层问题，见时钟同步方案 §7 |
