# 多通道同步验收测量设计

SofGated（[状态同步设计.md](./状态同步设计.md) §3.1）与软件 Present Barrier（[帧同步设计.md](./帧同步设计.md)）开发前的**基线测量**：当前 Async / FreeRun 下链路、帧预算、接缝观感各是什么水平。知识见 [状态同步总结.md](../../notes/状态同步总结.md) / [帧同步总结.md](../../notes/帧同步总结.md)。Slack 判定见帧同步设计 §3.6。补偿后仿真时间见 [时钟同步方案.md](./时钟同步方案.md) §4。

## 1. 范围与目标

| 纳入 | 不纳入 |
| --- | --- |
| 现行 FreeRun 下的基线：接缝、分段耗时、slack、`drainIncoming`、IGCtrl↔SOF RTT | 实现 SofGated / `ready`/`release`（见状态同步设计、帧同步设计） |

## 3. 约束（写死）

1. **不要用抓帧做帧阶段统计。** RenderDoc 适合偶发查 GPU。60Hz 连采用 `Engine::tickOnFrame` 内 `steady_clock` 打点：`preFrame` / `update` / `recordAndSubmit` / `waitForFences` / `present`。
2. **「渲完」不是 `recordAndSubmit` 返回。** 现行 `Engine::render` 是 submit → `present` → `waitForFences`。量 slack 必须先 fence 再 present（帧同步设计 §3.6）。整圈 `_lastFrameSeconds` 分不清哪些在等 VSync。
3. **UDP 收包已在 I/O 线程非阻塞 `recv`。** **IG** 主线程 `IgSync::drainIncoming` → `waitForUdpFrames`：空队列最多再等 **2ms**（两个 1ms I/O 轮询，状态同步设计 §5.1 / `kMaxUdpDrainWaitMs`）。有包立即返回。这 2ms 会直接吃 VBlank 空档，优先于「先改 TCP/UDP 策略」。**Host** `HostSync::drainIncoming` **不等待**（push 模式）。发送是调用方线程上的 `send`，不进 I/O 线程。
4. **跨机不能比本地单调钟。** 「各 IG Present 时的 QPC / `steady_clock` 差」没有公共钟就是噪声。能比的是包内 Host `TimeStamp` 和补偿后的 `simTimeUs`（同一套 Host 钟）。实验室两 IG 补偿后差小于一帧见 `CLK-consistent`。
5. **TCP 命令面无业务 ACK。** 「发一次 TCP 到收到」必须自定探针（例如 IG 回调时刻），不是现成回执。不在 Barrier 热路径上。
6. HUD 只放**本机、本帧、改配置当场能用的数**。百分位、通道间差、接缝走日志或眼睛。

## 4. 测量项

| 项 | 回答什么 | 形式 | 做法 |
| --- | --- | --- | --- |
| **4.1 接缝（网格 + 假眼点）** | Async 错帧/相位有多明显 | **一次性目视**（可录像）；眼点脚本可重复 | 场景用通道 JSON `groundGrid` 铺 **ENU 切平面线网格**（钉到指定 LLA 的 ECEF，**不加载** `readymap` 瓦片）。Host 发匀速眼点假数据扫过通道接缝（第 2 步，未做）。Barrier / SofGated 落地后再跑同一条对照。不代替数字 HUD |
| **4.2 一帧各阶段** | 预算花在哪 | **常驻统计** + HUD 上一帧分段 | `tickOnFrame` 打点。日志滚动 p50/p99 才能看掉帧尖峰。扩展现有 F2 HUD（已有 FPS / 整圈 frame ms / IGCtrl 号:`simTime`） |
| **4.3 渲完→VBlank（slack）** | 能不能开软件 Barrier | **先浸泡统计**，再决定是否进 HUD | 见帧同步设计 §3.6。低分位经常小于 2～3ms → 不开 Barrier。窗口模式可用 `DwmGetCompositionTimingInfo` 对照 |
| **4.4 IG `drainIncoming` 等待** | 空转 2ms 是否在偷帧 | **常驻统计 + HUD 一项 drain ms** | 只量 **IgSync**（Host 不等待）。若经常顶满 2ms，先改等待 |
| **4.5 IGCtrl 发出→收到 SOF** | 数据面 RTT、SofGated 门控会多重 | **Host 侧统计**；HUD 可显示最近/均值 | 见下方写死规则。`ready`/`release` 延迟的下限参照 |
| **4.6 同号 N 的 `simTimeUs`** | 时间特效会差多少 | **事后 CSV** | 列：帧号、包内戳、Present 时 `simTimeUs`、距上次收包年龄。HUD 只显示本机 `N` / `simTime` / age |
| **4.7 TCP 一发一收** | 命令面，非 60Hz 热路径 | **一次性 bench** | 自定探针时刻。命令面要优化再做，不挡 Barrier 决策 |

`release(N)` 之后仍是 `_viewer->present()`，没有第二种换缓冲（帧同步设计 §3.4）。

**§4.1 网格落地**：不加载地球瓦片。通道 JSON 写 `groundGrid`（[位姿配置设计.md](./位姿配置设计.md)）。单机 `vsgEngine.exe -c engine/resources/config/scene_seam_grid.json`；多通道一键 `scripts/run_seam_grid.sh`（或 `scripts\run_seam_grid.bat`），各 IG 用 `scene_seam_grid_ig_main.json` / `left` / `right`。切平面在 20 km 半幅边缘约离椭球面数十米，两 IG 同一网格，接缝仍可比。假眼点巡航是第 2 步。线格是 Vulkan `LINE_LIST` 实线（约 1 像素），由 `vsg::Builder` 的 wireframe 管线画出。

**§4.5 写死（IGCtrl↔SOF 应用 RTT）**：

- Host 墙钟配对；`t_recv` 是主线程 `drainIncoming` 见到 SOF 的时刻，不是 I/O `recv`。
- 按 Host Frame Number 配对（本项目 SOF `FrameCntr` 回显最近 IGCtrl）。禁止按到达顺序把「下一条 SOF」算给上一条 IGCtrl。
- 匹配时限 **100ms**：`now - tSend >= 100ms` 仍未匹配 → **丢失**，不把时限本身记进 RTT。99ms 到达仍匹配。
- 超时后晚到、同号重复 SOF、未知帧号：不进 RTT。飞行中既不算丢失也不进 RTT。
- 匹配与超时进同一滚动窗（最近 **60** 次完成）：`avgRtt` 只平均窗内匹配样本（窗内匹配满 **10** 才出）；`lossRate` = 窗内超时 / 窗内完成（完成满 **10** 才出）。飞行中不进窗。
- 按 peer 分列。IG 发送 socket 的源地址/端口在 `UDP_SYNC` 时记下，数据面 SOF 按该对落到对应 `SofRttTracker`（TCP 消息头 SOF 不计 RTT）。观测 `HostSync::sofRttLast(clientId)`。
- 不断言绝对毫秒黄金值；集成只要求有 \(\Delta > 0\) 的匹配样本。

## 6. 推荐顺序

1. **眼看基线**（4.1）：2～3 通道。决定 Barrier 有没有产品价值。
2. **帧预算 + drain + slack**（4.2～4.4）：决定 Barrier **允不允许做**。
3. **IGCtrl↔SOF RTT**（4.5）：SofGated / 栅栏延迟量级。
4. **同号时间 CSV**（4.6，可选）：要较真 shader 时间再做。
5. **TCP RTT**（4.7）：命令面要优化再做。

第 2 步已贴满 60fps：同步方案停在同一 Host 帧号扇出（已实现），不要进 `ready`/`release`。SofGated 仍可能做（不挡 Present），但 SOF RTT 和 drain 仍要先有数。

## 7. 验收要点

表征测量，不是 Present 产品收货（`PRES-*` 仍在帧同步设计 §6）。一经分配不改号。未写用例的码表示尚未落地。

| 码 | 场景 | 形式 | 验收 | Catch2 | 状态 |
| --- | --- | --- | --- | --- | --- |
| `MEAS-seam-grid` | Async 接缝基线 | 人工 / 录像 | 同一眼点轨迹下各 IG 接缝格子能否拼上；记录观感，供 Barrier 对照。网格本身：`groundGrid` 解析、钉到配置 LLA 的 ECEF | `[unit][sync][meas][MEAS-seam-grid]` / `[system][bdd][config][meas][resource][MEAS-seam-grid]`（几何/配置）；目视无 Catch2 | 网格已实现；假眼点未做 |
| `MEAS-stage-hud` | 分段耗时 | 注入 / HUD | F2 能看到上一帧 preFrame/update/submit/fence/present；日志可算 p99 | `[unit][sync][meas][MEAS-stage-hud]` | 未写（F2 仅有整圈 frame） |
| `MEAS-slack` | 渲完到 VBlank | 浸泡统计 | fence 后 present 的 slack 有 p50/低分位；判定是否满足帧同步设计 §3.6 | `[unit][sync][meas][MEAS-slack]` | 未写 |
| `MEAS-drain` | IG drain 等待 | HUD / 日志 | 能读出本帧 `IgSync::drainIncoming`（含 `waitForUdpFrames`）耗时；可发现顶满 2ms | `[unit][sync][meas][MEAS-drain]` | 未写 |
| `MEAS-sof-rtt` | IGCtrl→SOF | Host 统计 | 帧号配对记入 RTT；100ms 超时记丢失不进均值；晚到/重复/未知帧不进 RTT；飞行中既非丢失也非 RTT；最近 60 次完成同一时间轴上算 avgRtt / lossRate，满 10 才出；真链路有 \(\Delta > 0\) 的匹配样本 | `[unit][sync][meas][MEAS-sof-rtt]` / `[integration][sync][meas][MEAS-sof-rtt]` | 已实现 |
| `MEAS-simtime-log` | 同号仿真时 | CSV | 每帧能记下 N、包内戳、Present 时 `simTimeUs`、收包年龄；跨机不比 QPC | `[unit][sync][meas][MEAS-simtime-log]` | 未写 |
| `MEAS-tcp-rtt` | TCP 探针 | 一次性 | 自定「IG 收到」时刻下有 RTT 样本；不作为 Barrier 门槛 | `[integration][sync][meas][MEAS-tcp-rtt]` | 未写 |

两 IG 补偿后 `simTimeUs` 差小于一帧仍用时钟方案 `CLK-consistent`，不另开码。
