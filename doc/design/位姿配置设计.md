# 位姿配置设计

通道 JSON 用 **`coordFrame` + 双轨 pose** 描述实体摆放与相机初始位姿。与 Host→IG 运行时眼点正交（[lla位姿传输设计.md](./lla位姿传输设计.md)）。装配示意见 [坐标系统模块设计.md](./坐标系统模块设计.md) §2；**配置结构以本文为准**。

---

## 1. 方案

```text
coordFrame?: "Local" | "Ellipsoid"    // 缺省 Local；选中 pose 哪一半

entities: [                           // 取代顶层 string model / 单对象 entity；至少 1 项
  {
    id: int                           // 必填；数组内唯一；引擎 Map 主键
    name?: string                     // 可缺；缺省 = model 路径 basename（含扩展名）
    model: string                     // 必填
    pose?: { local?: LocalPose, ellipsoid?: EllipsoidPose }
  },
  …
]

camera? {
  pose?: { local?: LocalPose, ellipsoid?: EllipsoidPose }
}

LocalPose      { position[x,y,z], eulerYprDeg[yaw,pitch,roll] }      // 米 / 度；各数组长度须为 3
EllipsoidPose  { lla{lat,lon,alt}, eulerYprDeg[yaw,pitch,roll] }     // 度°/°/m；YPR 在 ENU
```

- 两半可并存、不互校；只消费 `coordFrame` 选中半。
- 单项 `pose` 可缺 → 引擎默认放置；`camera` / `camera.pose` 可缺 → **场景 AABB 默认初始相机**（§4）；有 `camera.pose` 则覆盖 LookAt。
- **顶层 `model`、单对象 `entity` 与 `entities` 互斥**（不可同时出现）；混写必须失败。空数组拒绝。
- 方案 A：未知键拒绝。
- 每项 `id`、`model` 必填；`id` 须为整数（非字符串）；缺省 / 非整数 / 数组内重复 → 解析失败。
- `name` 可缺；缺省填 `basename(model)`（例如 `models/lz.vsgt` → `lz.vsgt`）。`name` **不**作查找键，允许重复。
- 若某项 `pose` 或 `camera.pose` 出现：选中半必须存在，且该半字段齐全（含数组长度 3 / `lla` 三字段）。
- 位姿**不含 scale**（不写、不测）。
- `camera` 仍为单个，不数组化。
- 其余通道字段不变。

YPR：`Rz*Rx*Ry`，与 `setCameraPose` / LLA §3.2 一致。

引擎以 `id` 为主键维护 `map<int, Entity>`（见 §2）；按 id 唯一取实体（如 `sampleEntityPoseById`）；**禁止**用 `name` / `path` 作 Map 键。`coordFrame` 属通道，不进入 `Entity`。

## 2. 运行时 Entity

与 `entities[]` 一项对应。解析得到配置字段后，加载与装配补齐场景节点；引擎只保留运行时 `Entity`（不必再单拆只含配置的结构体，除非实现需要）。

```text
Entity {
  id: int                                 // ≡ JSON id；Map 主键
  name: string                            // ≡ JSON name；缺省已填 basename(model)
  path: string                            // ≡ JSON model（加载路径）
  localPose?: LocalPose                   // ≡ pose.local；可缺
  ellipsoidPose?: EllipsoidPose           // ≡ pose.ellipsoid；可缺
  node: vsg::Node                         // 模型子图（loadScene 结果）
  transform?: vsg::MatrixTransform        // node 的父节点；有选中半 pose 时必有
}
```

| 成员 | 来源 / 职责 |
| --- | --- |
| `id` / `name` / `path` | 配置；`path` 即 JSON `model` |
| `localPose` / `ellipsoidPose` | 配置双轨；optional，与 JSON 两半可缺一致 |
| `node` | 加载得到的模型根 |
| `transform` | 父 `MatrixTransform`；按通道 `coordFrame` 写 Local 或 Ellipsoid 矩阵（§3）。**无 pose（默认放置）→ `transform` 为空**（`node` 直接挂 scene，不建 MT） |

查找：`_entitiesById[id]` → `Entity`。采样 / 断言只认 `id`（`int`）。

---

## 3. 写入

| | Local | Ellipsoid |
| --- | --- | --- |
| 实体 | 父 **`MatrixTransform`**，`T(pos)*R(ypr)` | 父 **`MatrixTransform`**，`LocalToWorld(lla)*R_enu(ypr)` |
| 相机 | `setCameraPose` | `setCameraPoseLla` |

顺序：按 LLA §2 装配椭球 → 对 `entities` 逐项构造 `Entity`（`loadScene(model)` → 套 `transform` → `_entitiesById[id]`，挂同一 scene）→ 写初始相机（§4）。之后若 IG 已连接，仍由 Host 眼点 ⊕ `offsetDeg` 覆盖相机。

---

## 4. 默认初始相机（无 `camera.pose`）

**目标**：仅 `entities`、未配相机位姿时，Local / Ellipsoid 均用场景 AABB 取景，尽量框住当前内容。有 `camera.pose` 只覆盖 LookAt；Host 眼点仍可再覆盖。多实体相距很远时画面会稀疏——要好看请显式配 `camera.pose`。

**流水线**：

```text
ComputeBounds(_scene) → centre, radius
→ createInitialLookAt(ellipsoid?, centre, radius)
→ createInitialProjection(…)
→ 若有 camera.pose → 覆盖 LookAt
```

**Local**（世界笛卡尔）：

```text
eye = centre + (0, -1.5·radius, 0)；center = centre；up = (0,0,1)
Perspective near/far ∝ radius
```

**Ellipsoid**（禁止对 `centre` 套 Local 公式 / 世界 Z-up）：

```text
centre_ecef, radius ← AABB（centre 是场景盒子中心，≠ 地心）
lla_c = ECEF→LLA(centre_ecef)；取该点 ENU（east / north / up）
eye = centre_ecef - north·(k_back·radius) + up·(k_up·radius)   // 类比 Local 后退取景
LookAt(eye, centre_ecef, up)
EllipsoidPerspective(lookAt, ellipsoid, …)
```

`k_back` / `k_up` 为实现常量（建议 `k_back≈1.5`，`k_up≈0.2~0.5`）。AABB 空 / `radius≈0` / 换算失败 → fallback 写死 LLA `(39.9, 116.4, 500)`、YPR=0，并告警。

同配置同场景下 Host/IG 默认眼点应一致（不再依赖写死北京作唯一默认）；场景不同则默认可不同。

## 5. 示例

```json
{
  "coordFrame": "Ellipsoid",
  "entities": [
    {
      "id": 1,
      "model": "models/lz.vsgt",
      "pose": {
        "local": {
          "position": [0, 0, 0],
          "eulerYprDeg": [0, 0, 0]
        },
        "ellipsoid": {
          "lla": { "lat": 39.9, "lon": 116.4, "alt": 0 },
          "eulerYprDeg": [0, 0, 0]
        }
      }
    }
  ],
  "camera": {
    "pose": {
      "ellipsoid": {
        "lla": { "lat": 39.9, "lon": 116.4, "alt": 500 },
        "eulerYprDeg": [0, 0, 0]
      }
    }
  }
}
```

上例未写 `name`，解析后 `Entity.name` 为 `lz.vsgt`，`Entity.path` 为 `models/lz.vsgt`，`Entity.id` 为 `1`。

---

## 6. 不做

双轨自动换算、配置 scale、用本配置替代 CIGI 眼点权威；椭球默认用 AABB + 世界 Z-up。
