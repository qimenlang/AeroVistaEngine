## 2. ECEF 坐标系统

### 2.1 装配结构

```text
Scene
├─ setObject("EllipsoidModel", EllipsoidModel::create())   // 挂椭球参数(WGS-84)
└─ MatrixTransform(LocalToWorld(lla_model))                // 父节点:把模型钉到 ECEF
   └─ 现有 .vsgt 模型(顶点仍是本地笛卡尔)

Camera
   viewMatrix = LookAt(ecef_eye, ecef_center, local_up)    // 一次性初始化
   → Engine 检测到 EllipsoidModel → 自动切 EllipsoidPerspective + 椭球 Trackball
```

`EllipsoidModel` 只挂参数,不搬几何;真正让"World = ECEF"的是模型父节点 `MatrixTransform`,矩阵由 `computeLocalToWorldTransform(lla)` 生成。椭球投影与 Trackball 由 `engine.cpp` 现有 `getRefObject<EllipsoidModel>` 检测自动启用。

### 2.2 最小闭环步骤

```text
1. scene->setObject("EllipsoidModel", vsg::EllipsoidModel::create())   // 默认 WGS-84

2. 选测试 LLA(如北京地面: lat=39.9, lon=116.4, alt=0)
   auto mt = MatrixTransform::create(ellipsoid->computeLocalToWorldTransform(lla_model))
   mt->addChild(model);  scene->addChild(mt)

3. 相机初始 LLA 选模型上空(alt=500m 之类,能看到模型)
   eye    = ellipsoid->convertLatLongAltitudeToECEF(lla_cam)
   center = ellipsoid->convertLatLongAltitudeToECEF(lla_model)
   up     = normalize(eye)                    // 当地天向
   mainCamera->viewMatrix = LookAt::create(eye, center, up)

4. 运行,手动飞:地平线水平、椭球 Trackball 拖动正常、靠近/远离模型符合预期
```

启用开关由 JSON 中的 `injectEllipsoidIfMissing` 字段控制,详见 §3。

### 2.3 关键点与坑位

- **模型没有"LLA 坐标"**:`.vsgt` 顶点是本地笛卡尔,只能靠父 `MatrixTransform` 钉到 ECEF。`ComputeBounds` 会穿过该矩阵,bounds 中心自然是 ECEF 大数(~6.3e6 m)。
- **`up` 必须用当地天向**:世界 Z `(0,0,1)` 只在赤道 0° 经度恰好是天向,其他位置会导致地平线歪、Trackball 旋转轴错、近极点奇异。正确取 `normalize(ecef_eye)`(地表附近足够近似椭球法向),或取 `computeLocalToWorldTransform(lla_cam)` 第三列。
- **绕开旧 `setCameraPose`**:该 API 内部 `up = R(ypr) * (0,0,1)` 是世界 Z,椭球场景不成立。椭球初始化 / 运行时写入统一走 `Engine::setCameraPoseLla(lla, eulerYprDeg)`(内部 LLA→ECEF、`up` 取局部天向 / ENU 基),或直接构造 `LookAt(ecef_eye, ecef_center, local_up)`(详见 [lla位姿传输设计.md](./lla位姿传输设计.md) §3)。

## 3. 配置结构

场景 / 相机初始位姿的 JSON 结构、字段语义、解析与校验规则统一在 [位姿配置设计.md](./位姿配置设计.md)：

- 运行时坐标系由**场景有无 `EllipsoidModel`** 决定（消费 pose 哪半、写相机路径），非配置直接选择；`injectEllipsoidIfMissing`（bool）仅决定无自带椭球时是否注入（参与同步的场景自动注入）
- 场景实体走 `entities[]`（复数、数组），每项含 `id`、`model`、可选双轨 `pose`（`local` + `ellipsoid`），按 `int id` 建立 `_entitiesById` 主键
- 相机走 `camera.pose`，双轨结构同实体；椭球相机字段为 `lla + eulerYprDeg`（**不是** `lookAtLla`），运行时经 `Engine::setCameraPoseLla` 写 LookAt
- 顶层 `model` / 单数 `entity` / `entities` 三者互斥

本节早期版本曾描述单数 `entity` + `camera.ellipsoid.lookAtLla` 方案，已被上述配置文档取代，不再作为实现依据。
