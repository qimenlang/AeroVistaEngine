# 相机驱动总结

面向多通道同步驱动 IG 侧相机。详见 `../design/多通道同步模块设计.md` §1.2 / §4.8；椭球装配与默认初始相机见 `../design/lla位姿传输设计.md` §2；场景 JSON 位姿见 `../design/位姿配置设计.md`。

本文整理：VSG LookAt 与欧拉角、**Local / ECEF 默认初始相机**、相邻 frustum 偏航、Trackball、CIGI 报文对应。

---

## 1. 引擎现状

- `Engine::init` / `finishGraphicsAfterScene` 创建 `vsg::Camera` + `vsg::LookAt` + Projection，挂到 `View`；有窗口时再挂 `vsg::Trackball`（椭球场景传入 `EllipsoidModel`）。
- 主相机经 `Engine::mainCamera()` 暴露；位姿写入：`setCameraPose`（Local）/ `setCameraPoseLla`（椭球）。
- Local 场景默认世界 Z-up：`up = (0,0,1)`；椭球场景 `up` 为当地天向（ENU Up）。HUD 相机为 Y-up，勿混用。
- 另有 `vsg::LookDirection`（`position` + `quat`）；Trackball 要求 `LookAt`，主窗交互路径继续用 `LookAt`。

初始化顺序（无显式 `camera.pose` 时）：

```text
ComputeBounds(_scene) → createInitialLookAt → createInitialProjection → Camera
若 JSON 有 camera.pose → applyCameraPoseFromConfig（只改 LookAt，不改 Projection）
若 IG 已连 → Host 眼点 ⊕ offsetDeg 再覆盖 LookAt
```

## 2. LookAt 语义

```cpp
LookAt(eye, center, up);
// look = normalize(center - eye)
// 再与 up 正交化得到侧向与真正的 up
```

| 字段 | 含义 |
|------|------|
| eye | 眼点（相机位置） |
| center | 注视点（空间中的点，不是方向向量） |
| up | 参考上方向，用于定 roll；构造时正交化 |

要点：

- 视线方向 = `center - eye`。
- `center` 距离一般不改变朝向，但影响 Trackball 绕转半径。
- `up` 不是固定 `(0,1,0)`，取决于坐标系约定：**Local = 世界 Z；椭球 = 当地天向，不是正北**。正北是常见**视线**方向（YPR=0），不是 up。

## 3. 场景默认初始相机（无 `camera.pose`）

设计文档里：**Local** 用场景 AABB；**椭球**也按场景 AABB→LLA 推导初始相机（见 [位姿配置设计.md](../design/位姿配置设计.md) §4）。  
下文 §3.2 给出「椭球下从 AABB 得到 LookAt」的推导（**当前代码已实现该主路径**，见 §3.3）。

### 3.1 Local（世界笛卡尔）

```text
1. ComputeBounds(_scene) → 整场景 AABB（含所有实体 / MatrixTransform）
2. centre = (min+max)/2，radius ∝ |max-min|
3. LookAt(eye = centre + (0, -1.5R, 0), center = centre, up = (0,0,1))
4. Perspective：FOV / near/far 与 radius、aspect 相关
```

注意：AABB 包住**全部**物体；物体相距很远时相机会拉远，全体可见但稀疏。多实体分散时宜跟主实体或显式 `camera.pose`。

### 3.2 椭球 / ECEF（推荐：跟场景，而非世界轴套 Local）

ECEF 原点才是地心；AABB 中心是**场景内容**在 ECEF 下的几何中心（钉在地表时约在地表附近，距原点 ~6e6 m），**不是**地心。

不能把 Local 公式直接用在 ECEF 中心上：世界 `+Z` / `−Y` 不是当地天向 / 「退到模型南边」。应先落到 LLA，再用 ENU：

```text
1. ComputeBounds(_scene)           → 整场景 AABB（ECEF）
2. centre_ecef = (min+max)/2       → 场景盒子中心（≠ 地心）
3. lla_model = ECEF→LLA(centre_ecef)   // EllipsoidModel::convertECEFToLatLongAltitude
4. 相机 LLA：同 lat/lon，alt 抬高 H（或 ENU 内再偏一段再变回 ECEF）
     lla_cam = (lat, lon, alt + H)
5. 姿态：YPR=0 → 视线朝当地北；up = 当地天向（ENU Up）
6. 写 LookAt（与 setCameraPoseLla 同路径）：
     eye     = LLA→ECEF(lla_cam)
     north   = normalize(LocalToWorld(lla_cam) 北列)
     up      = normalize(LocalToWorld(lla_cam) 天列)
     center  = eye + north * d          // d 取 1 即可
     LookAt(eye, center, up)
7. Projection：EllipsoidPerspective(lookAt, ellipsoid, …)
```

| 量 | 含义 |
| --- | --- |
| 眼点 | 包围盒中心对应 LLA **上方**一定高度 |
| 视线（常见默认） | **正北**（当地 North） |
| up | **当地天向**，不是正北 |

有显式 `camera.pose` 时：仍只覆盖 LookAt（`setCameraPose` / `setCameraPoseLla`），Projection 保持按 bounds / 椭球创建的结果。

写死初始 LLA **只决定开机停在哪**；之后 Trackball（带 `EllipsoidModel`）或 `setCameraPoseLla` 会换成新的 ECEF LookAt，**不是**「离写死点越远公式误差越大」。

### 3.3 与当前实现 / 设计的关系

| 项 | 现状 |
| --- | --- |
| Local 默认 | 已按 §3.1：`createInitialLookAt` 用 AABB centre/radius |
| 椭球默认 | 已按 §3.2：`createInitialLookAt` 把 AABB centre ECEF→LLA 后经 `computeLocalToWorldTransform` 建 LookAt；仅 AABB 异常（中心过低/半径过小）时 fallback 写死 `(39.9°, 116.4°, 500 m)` |
| 禁止 | 椭球下用 AABB + 世界 Z-up 套 Local LookAt（lla §2.3） |
| 显式配置 | `camera.pose` → `applyCameraPoseFromConfig` |

若将椭球默认改为「跟场景」，实现应对齐 §3.2，并同步改 lla §2.3 / 验收中的写死 LLA 约定（Host/IG 默认仍须一致）。

## 4. 欧拉角与 LookAt 转换

### 4.1 协议 / 同步侧

与 CIGI 一致，线上传 `position + Yaw/Pitch/Roll`（或 `eye + quat`）。

不要在协议里传 `eye/center/up`（`center` 距离无标准、冗余）。

IG 本地再转成 `LookAt`。

IG 本地再转成 `LookAt`。

字段排列顺序（Yaw/Pitch/Roll）与 CIGI 一致；角度符号 / 轴系语义以本项目应用层约定为准（见 [多通道同步模块设计.md](../design/多通道同步模块设计.md) §4.2、[lla位姿传输设计.md](../design/lla位姿传输设计.md) §3.2）。

### 4.2 欧拉转 LookAt（设相机）

**已锁定约定**（同 [多通道同步模块设计.md](../design/多通道同步模块设计.md) §4.2）：

- 坐标系：Y-forward、Z-up（本地）；椭球为 ENU 局部（lla §3.2）。
- 旋转顺序：`Rz(yaw) * Rx(pitch) * Ry(roll)`。
- **作用于向量的生效顺序：先 roll、再 pitch、最后 yaw**。
- 单位：度。
- **VSG reverse-Hamilton 注意**：四元数 `a*b` 对应矩阵 `M(b)·M(a)`，故**禁止**把 `Rz*Rx*Ry` 写成 `Qz*Qx*Qy` 连乘（实际得到 `Ry*Rx*Rz`，生效顺序反）；应逐个作用 `roll→pitch→yaw`。

```text
eye     = position
forward = R(yaw, pitch, roll) * 前向轴
up_w    = R(yaw, pitch, roll) * 上向轴
center  = eye + forward * d          // d 取 1 即可
结果    = LookAt(eye, center, up_w)
```

对外可提供 `setPose(position, ypr)`，内部写 `camera->viewMatrix` 上的 `LookAt`。

### 4.3 LookAt 转欧拉（读主窗眼点出站）

```text
forward  = normalize(center - eye)
从 forward + up 解出 yaw/pitch/roll（同一套约定）
position = eye
```

注意万向节与约定歧义。跨进程更稳妥可传 quat 或 forward/up，欧拉作调试入口。

## 5. 多通道相邻 frustum

同步语义：共用眼点 / 主 view；各通道本地叠标定，而不是三份完全相同的 camera。

### 5.1 水平硬拼（无重叠）

投影参数一致（vFOV、aspect、near/far）时，靠相对主视向的偏航拼接：

```text
aspect = 宽 / 高
hFOV   = 2 * atan(aspect * tan(vFOV / 2))   // VSG 用垂直 FOV

中通道：channelYaw = 0
左通道：channelYaw = +hFOV    // 符号以实际朝向约定为准
右通道：channelYaw = -hFOV
```

边缘融合：

```text
channelYaw = +/-(hFOV - overlap)
```

### 5.2 应用方式

```text
共用：eye + 主朝向（Host 同步）
本通道：主朝向再绕 up 旋转 channelYaw，然后写 LookAt
投影：各通道 ViewDef / 本地配置，不随每帧眼点包重复发
```

IG 侧（engine）直接应用 sync 眼点写相机，不再依赖 Host 同进程的 UDP 自环（2026-08 拆进程后眼点由独立 viewhost 下发，见 [viewhost设计.md](../design/viewhost设计.md)）。

## 6. VSG 相机事件处理（Trackball）

### 6.1 机制

- Trackball 构造时：`camera->viewMatrix.cast<LookAt>()`，持有同一份 `_lookAt`。
- 鼠标 / 键盘 / 触控及惯性（`FrameEvent` / throw）直接改 `eye/center/up`。
- 与外部 `setPose` 争用同一 `LookAt`。
- 椭球场景：`Trackball::create(camera, ellipsoidModel)`，按当地天向更新。

### 6.2 所有权

| 角色 | 谁写相机 | Trackball |
|------|----------|-----------|
| IG（同步驱动） | SynchronSystem（合成后的 `takePendingCameraPose`） | 关闭或不挂 |

> 拆 Host 进程（2026-08）后 engine 只剩 IG 角色：Trackball/本地输入属独立 viewhost 进程（`viewhost设计.md` §4.4），不再与本进程同步写相机冲突。

### 6.3 Loop 相位

```text
IG 侧（engine）：handleEvents -> preFrame（IgSync 收包 -> SynchronSystem 合成）-> update 时取 pose 写 camera -> render
Host 侧（viewhost）：UI 定时器 -> 键盘累积眼点 -> outMsgWithIgCtrlUdp << 眼点 -> flushUdp 扇出
```

对应帧循环：

```text
advanceToNextFrame
-> handleEvents
-> （此处插 sync 应用或读出）
-> update
-> recordAndSubmit
-> present
```

## 7. CIGI 报文对应（位姿）

CIGI 无 LookAt 报文，标准是位置 + YPR。

| 报文 | 内容 | 用途 |
|------|------|------|
| EntityPositionCtrl（V4；旧版在 EntityCtrl） | 世界 Lat/Lon/Alt（或附着 XYZ）+ YPR；EntityID=0 为 ownship | 共用眼点 / 主姿态（高频） |
| ViewCtrl | 相对附着实体的 XYZ Off + YPR（机体系）；`*En` 表该项是否更新 | 座舱偏移、通道相对主视向偏航等；非世界绝对位姿 |
| ViewDef | FOV near/far/left/right/top/bottom | 投影 / 视锥，非位姿 |
| PositionResp | IG 到 Host 的查询回传 | 不用于驱动相机 |

线契约（椭球）：Detach + LLA；本地：Attach + XYZ。线上**无私有** `coordFrame` 字段；详见 lla §5、多通道同步 §4.8。

### 7.1 ViewCtrl 详解

ViewCtrl 控制「某个 View 挂在哪个实体上、相对该实体怎么偏」，不负责世界绝对位姿。

```text
Entity（ownship）
  <- EntityPositionCtrl：世界位姿
  └── View（某路相机）
        <- ViewCtrl：相对实体的 XYZ Off + YPR
        └── 投影参数 <- ViewDef
```

最终位姿：

```text
worldPose(view) = worldPose(entity) * offset(XYZ) * relative(YPR)
```

字段：

- `EntityID`：附着实体（常见 0 = ownship）
- `ViewID` / `GroupID`：控制单路或一组 View
- `X/Y/Z Off`：沿实体机体系平移
- `Yaw/Pitch/Roll`：相对实体机体系的姿态偏置
- `*En`：该项本帧是否有效；false 则保留上次

多通道推荐拆分：

1. 共用眼点 -> EntityPositionCtrl
2. 通道偏航 -> 本地标定，或 ViewCtrl 相对 Yaw
3. 视锥 -> ViewDef / 本地

## 8. 落地顺序（建议）

1. Engine 持有 mainCamera，提供 `setCameraPose` / `setCameraPoseLla`（内部写 LookAt）——已落地。
2. IG：禁用 Trackball，用 sync 的 position+YPR 写 main LookAt（先单通道）——已落地。
3. Host：viewhost 进程键盘累积眼点 -> `outMsgWithIgCtrlUdp << 眼点` -> `flushUdp` 扇出——已落地（2026-08 拆进程后独立 viewhost，见 [viewhost设计.md](../design/viewhost设计.md)）。
4. 各通道 `offsetDeg` / `channelYaw` 标定——yaw 已落地；pitch/roll 非零暂不支持。
5. 椭球默认初始相机由写死 LLA 改为 §3.2 AABB→LLA——**已落地**（`createInitialLookAt` 主路径按 AABB；写死 LLA 仅作异常 fallback）。
