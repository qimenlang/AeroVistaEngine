# 相机驱动总结

面向多通道同步驱动 IG 侧相机。详见 `../design/多通道同步模块设计.md` 第 1.2 节。

本文整理：VSG LookAt 与欧拉角、相邻 frustum 偏航、Trackball 事件处理、CIGI 报文对应。

---

## 1. 引擎现状

- `Engine::init` 创建 `vsg::Camera` + `vsg::LookAt`，挂到 `View`；有窗口时再挂 `vsg::Trackball`。
- 相机目前是局部变量，未作为 `Engine` 成员暴露；驱动前需持有 `_camera` / `_lookAt`。
- 场景相机默认 Z-up：`up = (0,0,1)`；HUD 相机为 Y-up，勿混用。
- 另有 `vsg::LookDirection`（`position` + `quat`），更接近位姿语义；但 Trackball 要求 `LookAt`，主窗交互路径应继续用 `LookAt`。

---

## 2. LookAt 语义

```cpp
LookAt(eye, center, up);
// look = normalize(center - eye)
// 再与 up 正交化得到侧向与真正的 up
```

| 字段 | 含义 |
|------|------|
| eye | 眼点（相机位置） |
| center | 注视点（空间中的点，不是方向向量） |
| up | 参考上方向，用于定 roll；构造时正交化 |

要点：

- 视线方向 = `center - eye`。
- `center` 距离一般不改变朝向，但影响 Trackball 绕转半径。
- `up` 不是固定 `(0,1,0)`，取决于坐标系约定。

## 3. 欧拉角与 LookAt 转换

### 3.1 协议 / 同步侧

与 CIGI 一致，线上传 `position + Yaw/Pitch/Roll`（或 `eye + quat`）。

不要在协议里传 `eye/center/up`（`center` 距离无标准、冗余）。

IG 本地再转成 `LookAt`。

字段排列顺序（Yaw/Pitch/Roll）与 CIGI 一致；角度符号 / 轴系语义以本项目应用层约定为准（见 [多通道同步模块设计.md](../design/多通道同步模块设计.md) §4.2、[lla位姿传输设计.md](../design/lla位姿传输设计.md) §3.2）。

### 3.2 欧拉转 LookAt（设相机）

**已锁定约定**（同 [多通道同步模块设计.md](../design/多通道同步模块设计.md) §4.2）：

- 坐标系：Y-forward、Z-up（本地）；椭球为 ENU 局部（lla §3.2）。
- 旋转顺序：`Rz(yaw) * Rx(pitch) * Ry(roll)`。
- **作用于向量的生效顺序：先 roll、再 pitch、最后 yaw**。
- 单位：度。
- **VSG reverse-Hamilton 注意**：四元数 `a*b` 对应矩阵 `M(b)·M(a)`，故**禁止**把 `Rz*Rx*Ry` 写成 `Qz*Qx*Qy` 连乘（实际得到 `Ry*Rx*Rz`，生效顺序反）；应逐个作用 `roll→pitch→yaw`。

```text
eye     = position
forward = R(yaw, pitch, roll) * 前向轴
up_w    = R(yaw, pitch, roll) * 上向轴
center  = eye + forward * d          // d 取 1 即可
结果    = LookAt(eye, center, up_w)
```

对外可提供 `setPose(position, ypr)`，内部写 `camera->viewMatrix` 上的 `LookAt`。

### 3.3 LookAt 转欧拉（读主窗眼点出站）

```text
forward  = normalize(center - eye)
从 forward + up 解出 yaw/pitch/roll（同一套约定）
position = eye
```

注意万向节与约定歧义。跨进程更稳妥可传 quat 或 forward/up，欧拉作调试入口。

## 4. 多通道相邻 frustum

同步语义：共用眼点 / 主 view；各通道本地叠标定，而不是三份完全相同的 camera。

### 4.1 水平硬拼（无重叠）

投影参数一致（vFOV、aspect、near/far）时，靠相对主视向的偏航拼接：

```text
aspect = 宽 / 高
hFOV   = 2 * atan(aspect * tan(vFOV / 2))   // VSG 用垂直 FOV

中通道：channelYaw = 0
左通道：channelYaw = +hFOV    // 符号以实际朝向约定为准
右通道：channelYaw = -hFOV
```

边缘融合：

```text
channelYaw = +/-(hFOV - overlap)
```

### 4.2 应用方式

```text
共用：eye + 主朝向（Host 同步）
本通道：主朝向再绕 up 旋转 channelYaw，然后写 LookAt
投影：各通道 ViewDef / 本地配置，不随每帧眼点包重复发
```

主窗本地通道直接应用眼点，勿依赖 UDP 自环。

## 5. VSG 相机事件处理（Trackball）

### 5.1 机制

- Trackball 构造时：`camera->viewMatrix.cast<LookAt>()`，持有同一份 `_lookAt`。
- 鼠标 / 键盘 / 触控及惯性（`FrameEvent` / throw）直接改 `eye/center/up`。
- 与外部 `setPose` 争用同一 `LookAt`。

### 5.2 所有权（必须二选一）

| 角色 | 谁写相机 | Trackball |
|------|----------|-----------|
| 主窗（本地输入为准） | Trackball / 本地输入 | 保留 |
| 从窗 / IG（同步驱动） | SynchronSystem | 关闭或不挂 |

主窗关闭本机 IgSync 对相机的覆盖，避免与 Host 出站互相打架。

### 5.3 Loop 相位

```text
preFrame: IgSync 收包 -> 写 camera（从窗）-> update / render
主窗：handleEvents（Trackball）之后 -> 读最终 eye -> HostSync 扇出
```

对应 `renderOneTick`：

```text
advanceToNextFrame
-> handleEvents
-> （此处插 sync 应用或读出）
-> update
-> recordAndSubmit
-> present
```

## 6. CIGI 报文对应（位姿）

CIGI 无 LookAt 报文，标准是位置 + YPR。

| 报文 | 内容 | 用途 |
|------|------|------|
| EntityPositionCtrl（V4；旧版在 EntityCtrl） | 世界 Lat/Lon/Alt（或附着 XYZ）+ YPR；EntityID=0 为 ownship | 共用眼点 / 主姿态（高频） |
| ViewCtrl | 相对附着实体的 XYZ Off + YPR（机体系）；`*En` 表该项是否更新 | 座舱偏移、通道相对主视向偏航等；非世界绝对位姿 |
| ViewDef | FOV near/far/left/right/top/bottom | 投影 / 视锥，非位姿 |
| PositionResp | IG 到 Host 的查询回传 | 不用于驱动相机 |

### 6.1 ViewCtrl 详解

ViewCtrl 控制「某个 View 挂在哪个实体上、相对该实体怎么偏」，不负责世界绝对位姿。

```text
Entity（ownship）
  <- EntityPositionCtrl：世界位姿
  └── View（某路相机）
        <- ViewCtrl：相对实体的 XYZ Off + YPR
        └── 投影参数 <- ViewDef
```

最终位姿：

```text
worldPose(view) = worldPose(entity) * offset(XYZ) * relative(YPR)
```

字段：

- `EntityID`：附着实体（常见 0 = ownship）
- `ViewID` / `GroupID`：控制单路或一组 View
- `X/Y/Z Off`：沿实体机体系平移
- `Yaw/Pitch/Roll`：相对实体机体系的姿态偏置
- `*En`：该项本帧是否有效；false 则保留上次

多通道推荐拆分：

1. 共用眼点 -> EntityPositionCtrl
2. 通道偏航 -> 本地标定，或 ViewCtrl 相对 Yaw
3. 视锥 -> ViewDef / 本地

---

## 7. 落地顺序（建议）

1. Engine 持有 `_camera` / `_lookAt`，提供 get/set（内部走 LookAt）。
2. IG：禁用 Trackball，用 sync 的 position+YPR 写 main LookAt（先单通道）。
3. Host：Trackball 驱动 -> 读 eye/YPR -> HostSync 发出。
4. 再加各通道 `channelYaw` 标定。
